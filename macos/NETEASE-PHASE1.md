## 功能与使用

- 网易云面板新增“私人FM”。打开不播放，点击“开始私人FM”启动；切换分类或关闭面板继续播放。
- FM按剩余曲目补批次。下一首只跳过；“不再推荐”需在面板内确认，提交云端负反馈，确认成功才切歌。
- 歌曲行和网易云当前曲目操作区共用喜欢按钮。显示最后目标和同步中状态，云端确认后更新；超时先读取核对，最多补发一次。未能核对显示结果待确认。
- 登录刷新喜欢ID；网易云面板可见且游戏有焦点时每5分钟刷新，另有“刷新云端喜欢状态”。隐藏期间不轮询；失败保留已确认数据。
- 128/320 kbps设置从下次加载生效；显示服务端实际返回码率、降级和试听状态，不能据此宣称输出bit-perfect。
- 取址在线验证后匹配缓存，每次加载均有重新取得首选音质的机会。第一批不提供离线播放。

FM最多保留20首历史、30首待播、100个近期ID；续批最多一个请求。空批次/全重复/网络错误追加2次重试（2秒、5秒），然后显示重试。连续5首曲目权限/格式等不可播放后停止推进；音频输出异常不按自然结束跳歌。暂停或其他音源取得播放权时取消续批，明确恢复后才继续。

## 配置与缓存兼容

现有 `config/musicbridge.options.json` 的 SchemaVersion 保持1。旧配置缺少下列字段时采用默认值：

```json
{
  "SchemaVersion": 1,
  "Netease": {
    "PreferredQuality": 128,
    "AutoRefreshFavorites": true,
    "FavoritesRefreshInterval": "00:05:00"
  }
}
```

`PreferredQuality` 只接受128或320；刷新间隔1分钟至24小时。UI更改音质使用原子保存，保留其他配置字段；首次写入前将已有配置备份为 `musicbridge.options.json.before-netease-v1`。非法原配置不会被UI静默覆盖。

新缓存位于 `cache/audio/v2/netease/<account>/`，索引按歌曲、请求音质和试听类型分区，记录实际码率、格式、大小、SHA-256、服务端摘要及试听范围。不记录临时播放URL。音频通过Unity解码后才尝试写缓存，磁盘失败不阻止本次播放；不完整的音质/试听元数据不用于缓存命中。

旧 `<songId>.mp3` 不作新版命中，不主动整体删除；正常容量淘汰会计入新旧数据。下载取消不提交新索引；活动缓存文件受租约保护，损坏后最多从网络重取一次。

### 耳机切换缺陷与修复版1.3.0.1

用户现场发现断开/连接耳机会切歌。Unity日志中设备切换的临时重连提示后紧跟“当前曲目播放结束”，确认此前只屏蔽最终输出失败不足以保护曲目结束判断。

修复将临时设备切换信号与最终输出故障分开：临时变化立即冻结结束判断，稳定2秒后从最后可信进度重载同一首，保留暂停/播放意图；不会因普通切换调用全局AudioSettings.Reset。增加播放进度可信性检查，拒绝与真实经过时间不符的末尾/零点跳变，显式seek、暂停恢复和真正自然结束仍可用。

1.3.0.1另增加不含账号和歌名的FM有效批次计数日志，便于严格核对跨三批实机行为。离线断言106项通过（本批共新增87项），完整Mac构建成功。新DLL SHA-256：`80f96bdf1db1fbc238de4cd67ee253fb13325736e2778d00b019567acd4ba418`。1.3.0.0备份位于 `.local/netease-phase1-backups/20260922-173242`；最初旧版备份仍保留。

### 暂停进度修复版1.3.0.2

1.3.0.1现场确认已不误切歌，但暂停期间耳机切换后，手动恢复会从开头播放。修复保持暂停中新加载音频的可信进度，不用尚未启动的AudioSource时间覆盖；真正恢复时先启动/解除暂停再seek到保存位置。增加模拟Unity Play将时间归零的回归测试。

1.3.0.2完整Mac构建成功，C#离线断言108项通过（本批新增89项）。DLL SHA-256：`e75021952b18ffd21f4ac18ceaad6680db3e6ff293d04ba7292374f680ae962b`。已备份1.3.0.1至 `.local/netease-phase1-backups/20260922-173946` 并安装。随后用户复测确认暂停恢复位置与自然续播均正常。
